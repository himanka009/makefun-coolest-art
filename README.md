# The Last Lighthouse

A basalt spire sends its last signal across the face of an eclipse. The image is rendered from equations, including the corona, ocean reflections, rock strata, and film grain.

Run with Python 3.13 and its standard library.

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The renderer writes a deterministic 768 × 768 RGB PNG to `out/entry.png`. In Make.fun's sandbox it writes to `/output/entry.png` by default.
